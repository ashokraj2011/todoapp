## Repository orientation {#core.brief}
This repository is a small Vite + React todo app. Its main capability is browser-based todo creation, completion, and removal. The app is centered in src/App.jsx and mounted by src/main.jsx. The standard validation commands are npm run build and npm run lint. The biggest risk is that the product is intentionally minimal: todo state is local-only and there are no automated tests.
